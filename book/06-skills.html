Turn a good habit into a skill

A prompt starts a task. A skill preserves a procedure.

Use three layers of context. The task prompt describes the immediate outcome. AGENTS.md records stable repository conventions. A skill packages a procedure that is worth repeating across relevant tasks. Avoid copying the entire game brief into every layer; duplicated instructions are easy to contradict.

Codex discovers repository instructions and scoped overrides through its instruction-file mechanism. Keep root instructions short and inspect any parent or nested rules that affect the working directory. The details of discovery belong to the official documentation. {{cite:07}}

A narrow skill: review a playable milestone

OpenAI documents skills as directories containing a SKILL.md with name and description, optionally with scripts and reference files. Repository skills can live under .agents/skills. A clear description helps the agent choose the procedure when it is relevant. {{cite:08}}

{{prompt:game-review-skill.md}}

Save this example as .agents/skills/game-review/SKILL.md in the game repository. Mention the skill in a task, or use the skill selector exposed by your agent host. Availability and invocation syntax can differ across the desktop app, CLI, and other hosts; confirm the skill is visible before relying on it.

Keep tools and procedures distinct

A review skill can say “inspect the running game,” but it does not install a browser, grant editor access, or make screenshots appear. Confirm that the agent has the necessary tools. If it lacks them, have it complete the checks it can run and give you the precise manual sequence for the rest.

A useful skill contains a trigger, a short sequence, the expected evidence, and an exit condition. Add a script only when a repeated action is stable enough to automate. Do not install a large collection of skills merely to make the prompt look more powerful; start with the few procedures the project actually needs.

When a skill becomes the problem

If the agent pauses or changes direction because of a file, ask for the file path and the exact instruction responsible. Resolve the conflict explicitly. A skill should make the workflow easier to execute, and should remain subordinate to the applicable instruction hierarchy.
