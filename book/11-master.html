The Astra master prompt

Use a compact request when the repository already holds the detail.

This is an original worked execution prompt for the Signal Garden brief. It is a manually authored example of the output the previous chapter asks for, not a transcript of an experiment or a benchmarked best prompt. Use it in a coding-agent session with the intended game folder open and GPT-6 Astra selected.

Before pasting, confirm the agent can edit the folder, run the package manager, and inspect a browser if you expect automated playtesting. The prompt allows reasonable local implementation choices and asks the agent to continue through the scoped milestones.

Publication is handled separately in the deployment chapter so the destination can be explicit.

Why these parts are present

  • The player promise gives the work direction.
  • The coordinate convention prevents integration mistakes.
  • The terminal-state rules settle edge cases.
  • The milestones make partial progress recoverable.
  • The evidence requirements make completion reviewable.
  • The exclusions keep the first game small enough to finish.

The model-specific portion is short: state how much initiative is expected, how to handle instruction conflicts, when delegation helps, and what test scope is appropriate. Those concerns are reflected in OpenAI’s current Astra guidance. The game rules and target values are our design choices. {{cite:01}}

Steer the active task with evidence

Do not restart from scratch after every disappointing result. A focused correction should name the current revision, the observed problem, the desired behavior, and the acceptable scope of change. Keep the overall objective intact while correcting the specific failure.

{{prompt:repair-prompt.md}}

If the agent cannot reproduce the problem, ask it to inspect the simplest relevant scene or add a narrowly scoped observation point. If it proposes another broad rewrite, require an explanation of why a local change cannot solve the problem and a recovery point before proceeding.
