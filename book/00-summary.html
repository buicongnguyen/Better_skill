Quick summary

The main points and the shortest path through the book.

  • Start small: one playable loop with clear completion rules.
  • Add only useful guidance: skills can help, but availability does not guarantee correct selection or better results.
  • Judge the result: play it, record evidence, and improve one cause at a time.
Start here

New to the tools? Follow environment setup first. Ready to work? Open the copy-and-paste cookbook: one prompt per step, expected outputs, and links to the full explanation.

The concise steps

  1. Define the game. Write the objective, controls, win/loss rules, and exclusions. The working loop → · Full game brief → · Copyable prompt →
  2. Choose a manageable approach. Match the workflow and engine to your biggest unknown; test a tiny browser export. Compare approaches → · Choose the stack → · Copyable prompt →
  3. Check the evidence. Match advice to the model and installed versions. Non-Astra benchmarks do not prove Astra gains. Research method → · Copyable prompt →
  4. Give the project a memory. Save the brief, acceptance checks, commands, and progress in Git; review changes before committing. Repository setup → · Copyable prompt →
  5. Check tools and skills. Reuse relevant available guidance; add a skill only for a demonstrated gap. MCP connects capabilities; hooks respond to events. Skill decisions → · Decision and data flows → · Copyable prompt →
  6. Give Astra a focused request. Use the compact prompt with accurate project files, or the bootstrap for an empty folder. A meta-prompt is optional. Execution prompts → · Prompt designer → · Copyable prompt →
  7. Build in playable stages. Setup → movement → win loop → loss/challenge → visual polish → release checks. M0–M5 plan → · Copyable prompt →
  8. Verify real play. Test controls, collision, pause, win, loss, and restart. Observe a human playtest. Full verification guide → · Copyable prompt →
  9. Fix, then distill. Save prompts and outcomes, repair the cause, and retain verified lessons. Compare P1/P2 from the same baseline before claiming a better prompt. Refinement method → · Copyable prompt →
  10. Publish and check. Build for the chosen host and URL path, deploy when authorized, then verify the expected revision and a complete run at the public URL. GitHub Pages walkthrough → · Copyable prompt →
  11. Optional: make a trailer. Use real capture for gameplay, label generated concepts, compose the clips, and review the final export. Video workflow → · Copyable prompt →
