Choose the right workspace

Pick the stack your agent can build and you can judge.

The game’s delivery platform should influence the engine choice early. For a small game intended to live at a GitHub Pages URL, a browser-native stack offers a direct path from code changes to a playable link. For an existing Godot or Unity project, preserving the engine may be more useful than switching to match a fashionable workflow.

These are practical selection criteria, not benchmark results or a complete feature comparison. Test the cheapest risky part before committing to the stack. If the agent cannot reliably inspect the editor, begin with a tiny scene and an export test to discover that limitation immediately.

Our default: Three.js, TypeScript, and Vite

Signal Garden uses a fixed, slightly elevated camera, a flat arena, simple geometric obstacles, and a small number of moving objects. That scope makes a browser codebase a reasonable teaching choice. Start with simple collision shapes and a readable state machine. If the design later depends on slopes, rigid-body interactions, or complex character movement, evaluate an appropriate physics solution before improvising one.

Use compatible stable package versions available when you start, commit the lockfile, and record the versions in the README. Use npm ci for a clean install from a matching committed lockfile; it fails on a package/lock mismatch rather than silently updating the lock. Avoid copying an old tutorial’s versions without checking compatibility. Demonstrate the chosen renderer on the target browsers. {{cite:42}}

If you choose Godot instead

For a straightforward Pages release, begin by testing a GDScript project with Compatibility rendering and a single-thread web export. Godot’s documentation states that web exports use WebGL 2, that Godot 4 C# projects currently cannot export to web, and that threaded exports require cross-origin isolation. These are version-sensitive constraints. {{cite:11}}

Prove an empty scene’s exported build loads at the final project URL before building a full game. Keep the export files together. The HTML entry can be named index.html; keep the other generated files’ names unchanged. Godot also documents a PWA service-worker workaround for isolation, so the single-thread recommendation is a simple starting route, not proof that every threaded Pages deployment is impossible. {{cite:11}}

The 30-minute feasibility check

As a timeboxed exercise, create a floor, one object, and a camera. Make the object move, build the output, and serve it under a repository subpath. Record what failed. The timebox is a planning suggestion, not a promised completion time.
